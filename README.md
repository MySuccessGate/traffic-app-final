# Traffic Intelligence System

Plateforme d'aide à la décision pour la prédiction du trafic horaire.

## Fonctionnalités
- Prédiction probabiliste du trafic
- Explicabilité du modèle (SHAP)
- Simulation de scénarios
- Interface interactive avec Streamlit

## Technologies
- Python, XGBoost, Streamlit, SHAP
